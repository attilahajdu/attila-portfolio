# Attila Hajdu — portfolio

Static single-page site (`index.html`). GitHub’s repository name cannot include spaces; this repo is **`attila-hajdu-portfolio`**.

## Assets (add alongside `index.html` on your host)

The page expects these paths next to `index.html`:

- `ati-logo-25.png` — hero watermark
- `ai-is-here.png` — timeline section
- `/portfolio-ai-avatar-videos-2025/` — intro and portfolio MP4s (match your server layout or update paths in HTML)

## Deploy

Push this repo to GitHub, enable **GitHub Pages** (Settings → Pages → branch `main` / root), or upload the folder to any static host.
